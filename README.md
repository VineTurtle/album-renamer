# 图册批量重命名

给扫描图册、照片批量改名的本地小工具。界面在浏览器里，读写文件由本地 Node 服务完成。

## 启动

- 双击 `启动.bat`，会自动打开 `http://127.0.0.1:8787/`
- 也可以把整个图片文件夹**拖到 `启动.bat` 上**，打开后直接载入该文件夹
- 关闭黑色命令行窗口即退出

需要 Node.js 18+（你机器已装）。端口被占用时会自动顺延到 8788、8789…

## 基本流程

1. 点左上角文件夹图标，选择存放扫描图片的文件夹
2. 左侧填写命名模板，右侧实时显示“旧名 → 新名”
3. 需要时拖拽调整顺序、给封面/封底单独命名
4. 点右上角「执行重命名」，确认后落盘
5. 改错了点「撤销上次」回滚

## 命名模板

两种编辑方式，内容互相同步：

**分段**：每段是一个方块，点击可编辑，拖拽可换位置。

- `+ 文本`：固定文字，例如 `aaa`
- `+ 分隔符`：插入 `_`、`-`、`.`、空格
- `+ 序号`：自动编号，可加前缀后缀（`第`/`页`）和偏移
- `+ 原名`：原文件名（不含扩展名）
- `+ 原数字`：原文件名里最后一段数字（`IMG_0007` → `0007`）
- `+ 日期`：文件修改时间
- `+ 文件夹`：当前文件夹名

例如 `aaa` + `_` + `bbb` + `_` + `序号(4位)` + `_` + `ccc` → `aaa_bbb_0001_ccc.jpg`

**语法**：直接输入

```
aaa_bbb_{num:4}_ccc
图册A_{num:3}_第{num:2}页
{orig}_{date:YYYYMMDD}
```

| 占位符 | 含义 |
| --- | --- |
| `{num}` / `{num:4}` / `{0001}` | 序号，冒号后是补零位数 |
| `{orig}` | 原文件名 |
| `{digits}` | 原文件名里的数字 |
| `{date}` / `{date:YYYY-MM-DD}` | 修改日期 |
| `{folder}` | 文件夹名 |

编号规则（起始值、步长、补零、字母/中文数字、序号来源）在下方「编号规则」里设置。

## 封面、封底这些特殊页

两种做法，随便挑：

1. **单张命名**：选中封面 → 点「自定义名」→ 输入 `封面`。这张会锁定，**不占页码**，后面的正文仍然从 0001 开始。
2. **多模板**：点 `+ 新模板` 建一个「封面」，选中若干张 → 顶部「套用」选这个模板。每个模板独立计数，互不影响。

右键卡片 = 直接给这张命名。

## 选择文件夹

- 点左上角的文件夹按钮打开选择器，可以直接点磁盘、逐级进入
- 子文件夹很多时，用下面的过滤框输入关键字快速筛选；`Esc` 清空过滤，再按一次 `Esc` 关闭选择器
- 选中文件夹后按 `Enter` 直接进入第一项
- 返回上一级会**停在你离开时的位置**，并把刚进去的那个文件夹标成「← 刚才在这里」
- 关掉选择器再打开，同一位置也会保留

## 排序与选择

- 排序：文件名（自然排序，`2` 在 `10` 前）、修改时间、大小、手动
- 拖拽卡片可任意调整顺序；拖动时序号实时重算，排序会自动切到「手动顺序」
- 手动顺序只对当前这批文件有效：同一文件夹点「刷新」会保留，换文件夹或重新导入会恢复自然排序
- 单击选中，Ctrl 加选，Shift 连选，Ctrl+A 全选，Ctrl+F 定位到搜索框
- 双击看原图：滚轮以鼠标位置为中心缩放、拖动平移、←/→ 翻页、Esc 关闭
- 搜索框只过滤显示，不影响编号；`Esc` 清空搜索内容，再按一次取消选择
- 同一文件夹点「刷新」时，自定义名、排除状态、套用的模板都会保留（按文件名对应），新出现的文件排在最后

## 输出方式

- **原地重命名**：默认，两阶段临时名执行，支持 `A↔B` 互换
- **复制到新文件夹**：原件完全不动
- **移动到新文件夹**：复制成功后删除原件

执行前会检查：重名、磁盘已有同名、Windows 非法字符、保留名（CON/PRN…）、超长文件名。有问题会标红并禁止执行。

## 撤销与记录

- 每次执行都会在目标文件夹写一份 `_rename-log-时间.json`
- 「撤销上次」按记录回滚：改名改回去、副本删除、移动移回
- 记录文件可以留着，不影响使用；不需要时手动删

## 导出清单

「导出清单」生成 CSV（UTF-8 BOM，Excel 直接打开不乱码），包含旧名、新名、完整路径、模板、大小、时间。

## 说明

- 只读取和改名，从不修改图片内容
- 默认只处理图片（jpg/jpeg/png/webp/bmp/gif/tif/tiff/avif/heic）；取消「仅图片文件」可处理全部文件
- 浏览器解不了的格式（如部分 HEIC）缩略图会显示“无法预览”，但仍可正常改名
- 所有设置存在浏览器本地，下次打开自动恢复（包括上次的文件夹）
